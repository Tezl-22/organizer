# Органайзер

Курсова робота: вебзастосунок «Органайзер» — задачі, нотатки, нагадування та календар.

Стек: Python 3.10+, Flask 3.1, SQLite (модуль `sqlite3`), шаблони Jinja2, CSS.

## Можливості

- **Задачі**: створення, редагування, видалення; пріоритет (низький / середній / високий), термін виконання, позначка «виконано»; фільтр за статусом і пріоритетом; прострочені задачі підсвічуються.
- **Нотатки**: створення, редагування, видалення, пошук за назвою і текстом (без урахування регістру).
- **Нагадування**: створення, редагування, видалення з датою і часом; сторінка з простроченими, найближчими (7 днів) і всіма нагадуваннями; банер на кожній сторінці.
- **Календар**: місячна сітка (з понеділка) із задачами та нагадуваннями, перехід до попереднього / наступного місяця.

## Запуск

Linux / macOS:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python seed.py          # необов'язково: демонстраційні дані (очищує базу!)
flask --app app run     # або: python app.py
```

Windows (PowerShell / cmd):

```bat
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python seed.py
flask --app app run
```

Відкрити в браузері: http://127.0.0.1:5000

База даних створюється автоматично під час першого запуску у файлі `instance/organizer.db`.

## Тести

```bash
python -m pytest -q
```

Автоматичні тести — `tests/test_app.py` (кожен тест працює з тимчасовою базою).
Ручні тест-кейси — `tests/test_cases.md`.

## Структура проєкту

```
app.py             маршрути Flask і перевірка введених даних
db.py              підключення до SQLite, класи-репозиторії з SQL-запитами
month_calendar.py  побудова сітки місяця для календаря
schema.sql         схема бази даних
seed.py            демонстраційні дані
templates/         HTML-шаблони Jinja2
static/style.css   стилі
tests/             автоматичні тести та тест-кейси
DESIGN.md          проєктні дані: ER, варіанти використання, маршрути, класи
```
